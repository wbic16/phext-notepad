Install Phext Notepad

A free Windows text editor for phext files. You do not need a GitHub account.

Download Phext Notepad

This is for a 64-bit Windows 10 or Windows 11 PC. The download is a file named setup.exe.

After it downloads

  1. Open setup.exe.
  2. If Windows says it protected your PC, click More info, then Run anyway. Windows does that when it does not already trust the publisher.
  3. If a window says the publisher is unknown, click Install.
  4. Open Phext Notepad from the Start menu or the desktop shortcut.

You need an internet connection the first time. setup.exe downloads the app and installs it for you. It does not ask you to install .NET yourself.

The next time a new version is published, Phext Notepad asks to update when you open it.

Source code and issues: github.com/wbic16/phext-notepad.
