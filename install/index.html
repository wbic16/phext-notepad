Install Phext Notepad

A free editor for phext files on Windows, macOS, and Linux. You do not need a GitHub account.

Windows

This installer is for a 64-bit Windows 10 or Windows 11 PC. It keeps itself up to date.

Download for Windows

The download is a file named setup.exe.

  1. Open setup.exe.
  2. If Windows says it protected your PC, click More info, then Run anyway. Windows does that when it does not already trust the publisher.
  3. If a window says the publisher is unknown, click Install.
  4. Open Phext Notepad from the Start menu or the desktop shortcut.

Native Windows installer

The native installer is a separate build. It does not update itself. Use it when you want the same app as the macOS and Linux builds.

macOS

This is a disk image for Apple silicon and Intel Macs.

Download for macOS

  1. Open the .dmg file and drag Phext Notepad to Applications.
  2. The app is not signed yet. If macOS says the developer cannot be verified, right-click the app, choose Open, then choose Open again.

Linux

Use the AppImage on most desktops, or the .deb package on Debian and Ubuntu.

Download for Linux (AppImage) Download .deb

For the AppImage, mark the file executable and open it. These builds are not signed.

The macOS, Linux, and native Windows buttons use the latest GitHub Release. They start working after a version is published. Until then they open the releases page.

The Windows setup.exe button needs an internet connection the first time. It downloads the app and installs it. It does not ask you to install .NET yourself. The next time a new version is published, that copy asks to update when you open it.

Source code and issues: github.com/wbic16/phext-notepad.
